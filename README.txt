DR. AASHLESHA BIRTHDAY WEBSITE

FILES TO UPLOAD TO YOUR GITHUB REPOSITORY
Keep index.html and all five JPG images in the SAME folder (repository root).

1. index.html                 (the website)
2. aashlesha.jpg              (her original photo on the opening screen)
3. cake.jpg                   (gift 1)
4. dyson.jpg                  (gift 2)
5. hair-clips-earrings.jpg    (gift 3: one image containing the hair clips and earrings)
6. watch.jpg                  (gift 4)

IMPORTANT IMAGE NAMING
- Use these exact filenames, including lowercase letters and hyphens.
- GitHub filenames are case-sensitive. For example, Cake.JPG is NOT the same as cake.jpg.
- If your image is currently named .jpeg or .png, either rename it to the exact .jpg filename or update the matching filename inside index.html.
- No images are included in this ZIP because you said you will add your own JPG files.
- Use your original photo as aashlesha.jpg; the website only displays it and does not edit it.

PUBLISH ON GITHUB PAGES
1. Open your repository on GitHub.
2. Choose Add file -> Upload files.
3. Upload index.html and the five JPG images listed above.
4. Commit the changes.
5. Open Settings -> Pages.
6. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
7. Open the Pages URL shown on that settings page. It may take a minute or two after committing changes.

WEBSITE FLOW
Opening screen with one photo and one button: “These gifts are for you ♡”
Then the gifts appear one by one: cake -> Dyson -> hair clips and earrings -> watch.
No gift-box picture or separate gift-box screen.
A small original synthesized melody can be toggled on/off using the Music control.
